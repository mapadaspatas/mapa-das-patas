# Imagens das Iniciativas

As imagens desta pasta entram pelo Cadastro: quem preenche o formulário do site
envia a foto, ela é recortada em quadrado e reduzida ainda no navegador de quem
envia, e chega aqui no mesmo pull request que traz o YAML da Iniciativa.

Vale só imagem que a própria Iniciativa publica ou autorizou: foto de perfil,
logo ou foto dos animais. Nenhuma imagem é buscada automaticamente em rede
social, e print de post ou de story é recusado na revisão, porque é por onde a
chave PIX de uma pessoa entra escrita na tela. Quem não tem imagem aparece no
site com um avatar de iniciais.

O nome do arquivo é o slug da Iniciativa, o mesmo do YAML em
`content/iniciativas/`.
